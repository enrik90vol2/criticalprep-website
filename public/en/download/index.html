Requirements

  • System: [macOS 14 Sonoma] or later.
  • Mac: Apple silicon recommended. Local AI with Ollama needs enough memory for the chosen model; Apple Intelligence requires a compatible Mac.
  • Discord session recording (optional): Node.js 20.9 or later and a Discord bot you create (the app guides you through setup).
  • Internet connection: only needed for the CriticalPrep AI subscription, a personal API key and updates.

Installation

  1. Open the downloaded DMG file.
  2. Drag CriticalPrep into the Applications folder.
  3. Open the app from the Applications folder. The app is signed and notarized by Apple, so macOS opens it normally.

CriticalPrep is distributed directly from this website, not through the Mac App Store. Updates are delivered by the app itself.
